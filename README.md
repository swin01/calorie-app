# 🍎 AI Calorie Analyzer

An AI-powered web application that analyzes food images and provides estimated nutritional information such as:

- 🔥 Calories
- 💪 Protein
- 🌾 Carbohydrates
- 🥑 Fats

Users can upload a food image or drag and drop an image into the application.

---

## 🚀 Features

- 📷 Food image upload
- 🖱️ Drag-and-drop image support
- 👀 Image preview
- 🤖 AI-powered food recognition
- 🔥 Calorie estimation
- 💪 Protein estimation
- 🌾 Carbohydrate estimation
- 🥑 Fat estimation
- 📊 Nutritional results displayed in cards
- 📱 Responsive design
- 🔥 Firebase integration
- ⚡ Fast and simple interface

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

### AI

- Groq API
- Llama vision model

### Image Hosting

- ImgBB API

### Backend / Hosting

- Firebase
